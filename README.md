# b2b-saas-revenue-analytics
End-to-end B2B SaaS revenue analytics project modeling MRR, expansion, contraction, churn, reactivation, and revenue retention to support Finance and GTM decision-making.
This project simulates an end-to-end B2B SaaS analytics workflow, from subscription history modeling and customer-level MRR calculation to revenue movement analysis and downstream insights for Finance, GTM, and Customer Success.
